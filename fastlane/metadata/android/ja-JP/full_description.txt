<p>paperless-android は、自分で運用する文書管理システム <a href="https://docs.paperless-ngx.com/">Paperless-ngx</a> のクライアントです。ご自身のサーバーとだけ通信し、それ以外にデータを送りません。</p>

<p><b>文書</b></p>
<ul>
<li>ダッシュボードの保存済みビューを並べたホーム画面</li>
<li>大きなサムネイルの文書一覧（オフラインでも表示）</li>
<li>全文検索と並び替え・絞り込み（タグ・担当者・文書の種類・保存先・作成日）</li>
<li>PDF・画像のビューワ：全画面表示、ピンチでの拡大、文書内の検索</li>
<li>メモ・カスタムフィールドの表示、タイトル・日付・ラベル・保存番号（ASN）の編集</li>
<li>共有・他のアプリで開く・ダウンロード・削除、ごみ箱からの復元</li>
<li>新しい文書を確認する受信箱</li>
</ul>

<p><b>文書の追加</b></p>
<ul>
<li>カメラで紙をスキャン：複数ページを撮影し、4 隅でのトリミングと補正をして 1 つの PDF としてアップロード</li>
<li>ファイルのアップロードや、他のアプリからの共有。複数の画像を 1 つの文書にまとめることも可能</li>
<li>アップロードは待ち行列に入り、ネットワークにつながるとバックグラウンドで送信</li>
</ul>

<p><b>整理</b></p>
<ul>
<li>タグ・担当者・文書の種類・保存先の管理</li>
<li>メニューからの保存済みビュー</li>
</ul>

<p><b>接続</b></p>
<ul>
<li>複数のアカウント・サーバー</li>
<li>パスワード（2 段階認証を含む）または API トークンでのサインイン</li>
<li>独自のリクエストヘッダー（アクセスゲートウェイ向けなど）、クライアント証明書（mTLS）、プライベート CA の証明書</li>
</ul>

<p>Paperless-ngx 3.0.0 以降（REST API バージョン 10）と Android 10 以降が必要です。</p>

<p>コミュニティアプリ paperless-mobile を参考にした独立したプロジェクトです。Paperless-ngx・paperless-mobile の各プロジェクトとは関係ありません。</p>
